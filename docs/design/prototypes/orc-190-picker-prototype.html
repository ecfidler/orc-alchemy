PROTOTYPE · ORC-190 Form Item Width Theme
What to look at
  • Four variants, switched with the bar at the bottom or the ← → keys. They use the same picker modal. They differ in how the picks sit on the form, and in how the background tool proficiencies are added.
  • A · Rows. Each pick is a full-width row with an X, and the add button is full width under the rows. Tool proficiencies: the button opens a list of six sub-selections (as the modifier list, a click adds one and closes). Each sub-selection then has its own control. Vehicles and Other tools have six items or fewer, so they are a checkbox row.
  • B · Cells. A small Add button sits in the section heading, so an empty section is one line. Picks are boxed cells in a grid. Tool proficiencies are one picker for all 28 options (with search), and an "Any …" pick carries a 1 / 2 / 3 toggle in its cell.
  • C · Ledger. Labels on the left. Picks are small tokens on one wrapping line, with a dashed "+ Add" token at the end. The same one-picker tool list as B.
  • The picker stays open after a pick, and the picked item leaves the list. Done, X, Escape or a click outside closes it. A list with more than 20 options has a search field (tools in B and C, equipment, the class spell lists). Skills and artisan's tools have none.
  • Item: New shows the empty form, with all five background sections in view. Class (part) shows the other controls: the saving throw checkbox row, the ability increase level chips, "Choose n" with picker rows, and the spell list pickers.
  • D · Rows layout + tokens. The layout of A (section rules, full-width add buttons, the sub-selection list for tools), with the picks as tokens on one wrapping line and not as rows.
