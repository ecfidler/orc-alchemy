# Prototypes

Copies of the throwaway HTML prototypes that the M8 theme decisions come from. Open a file in a browser. The [Theme spec](../theme.md) wins where a prototype disagrees with it.

* [Palette](orc-144-palette-prototype.html) - The palette in light and dark (ORC-144); variant C is the choice.
* [Character sheet](orc-145-sheet-prototype.html) - The sheet layouts (ORC-145, ORC-153); layout F is the choice.
* [Notes and bubbles](orc-146-marks-prototype.html) - The sticky note and the spent-ability bubble (ORC-146); note A and bubble D are the choice.
* [App shell](orc-147-shell-prototype.html) - The app shell and the logo slot (ORC-147); shell C is the choice.
* [Home page](orc-150-landing-prototype.html) - The landing page with the mug stain (ORC-150); variant C is the choice.
