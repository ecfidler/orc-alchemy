# Prototypes

Copies of the throwaway HTML prototypes that the M8 theme decisions come from. Open a file in a browser. The [Theme spec](../theme.md) says which view of each prototype is the choice, and it wins where a prototype disagrees with it.

* [Palette](orc-144-palette-prototype.html) - The palette in light and dark (ORC-144).
* [Character sheet](orc-145-sheet-prototype.html) - The sheet layouts (ORC-145, ORC-153).
* [Stuck note and use bubble](orc-146-marks-prototype.html) - The stuck note and the use bubble (ORC-146).
* [App shell](orc-147-shell-prototype.html) - The app shell and the logo slot (ORC-147).
* [Home page](orc-150-landing-prototype.html) - The landing page with the mug stain (ORC-150).
