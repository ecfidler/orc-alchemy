What to look at
  • Three variants, switched with the bar at the bottom (or the ← → keys). A: a "None / Fixed / Scaled" toggle and fields. B: one sentence line, "[3] uses, recharges [on a long rest]", with the scaled amounts in the same list as the numbers. C: the control from A, and the sheet preview for the whole item at the side, sorted into sections.
  • Imported opens a pack item with every case: fixed, a pool, proficiency bonus, a level × 5 pool (subclass), an ability modifier (feat), a feature with no uses whose text has a suggestion, and a rest from an old pack (Each round).
  • The preview shows the bubble, its tag and its sheet section. For scaled uses only, one line under it says how the amount is worked out for the example character.
  • Example character for scaled uses: level 5 and 16 in the ability, as the ticket suggests. Change both on the preview. A class or subclass feature counts the class level; others count the character level.
  • Delete (X) on a feature with content (a name, text, uses, or a type) asks first. An empty feature goes at once.
