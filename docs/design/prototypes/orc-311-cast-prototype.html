Prototype · ORC-311 · Cast button and level menu Character Control Place Slots Width
What to try
  • Wizard 5 / Warlock 3: Magic Missile and Burning Hands show a calculated number for each higher level. Magic Weapon has no number, so the menu shows its "At Higher Levels" text. Misty Step has no higher level text. Fireball has no higher slot, so it has no menu.
  • Cast Hold Person, then Invisibility: the second concentration spell asks first. True Strike is a cantrip with a "Concentrate" button. Fire Bolt has no button.
  • Set "Slots" to "No 1st-level" (Cast is disabled, the menu still works) and to "None left". The slot circles at the top also work with a click.
  • Warlock 11: only pact slots, so Cast has no menu. Circle of Death spends Mystic Arcanum. Bane spends Thief of Five Fates and a pact slot. Misty Step has its own uses and no link, so it has no Cast button.
  • "Control" switches between a split button, two buttons, and a row with one button for each level. "Place" puts the control beside the spell name or on its own row.
