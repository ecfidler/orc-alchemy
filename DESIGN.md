## Overview

**Creative North Star: "Paper"**

The app must feel like a physical character sheet, but it does not copy paper literally. The page is a slightly yellow off-white with a subtle grain. The text is graphite-dark, in a serif face. Boxes have plain borders, with the label under the value, as on a printed sheet. Color is rare and each color has one meaning: a yellow note for something the user must act on, red for a failure, blue for a limited-use feature and for focus.

The app shell is a binder. A margin rail on the left holds the logo and the navigation, and a red double rule separates it from the page. Each page of the navigation has a flat flag tab that is stuck to the rule.

The Dark theme is not dark paper. It is OLED black and white: a pure black page, white text, and accents that shift to suit black. The notes and the flag tabs stay bright in the Dark theme, with black text.

The authority for each value and rule in this file is `docs/design/theme.md`. When this file and `theme.md` disagree, `theme.md` wins. The homebrew forms are in `docs/design/homebrew-forms.md`.

**Key Characteristics:**

- Paper page, ink text, ink borders. No gradients and no decoration that a paper sheet could not have.
- Each color is a role token. The name says what the color does.
- Serif for content, small sans caps for labels.
- A sheet that a user reads in a few seconds at the table, on a laptop or a phone.
- Text labels only. There is no icon set.

## Colors

The palette is paper and ink, with marker accents. The frontmatter has the Light values, and the Dark values with a `-dark` suffix. A token with no `-dark` entry has the same value in the two themes.

### Primary

- **Ink** (#222222, Dark #ffffff): body text, values, the border of a button and of an active field, and the fill of a solid button.
- **Paper** (#fffcf5, Dark #000000): the page.

### Secondary

- **Note Yellow** (#ffe45c in the two themes): the fill of a stuck note, a yellow alert note, a note line, and the flash of a part that the user added. It means "you must act".
- **Info Blue** (#1e5fb4, Dark #5ea2ff): the outline of a use bubble and the focus ring. The bubble fill is 12% of this color on Raised Paper (18% in the Dark theme).

### Tertiary

- **Danger Red** (#c2271d, Dark #ff5c52): errors and "failed". The margin rule of the shell has the same values.
- **Success Green** (#1f7a3a, Dark #4ed07a): "Saved" and death-save successes.
- **Warning Yellow** (#7f6200, Dark #ffd93d): warning text that needs no action.
- **Caution Orange** (#b85a00, Dark #ff9a3d): a bad mark that is not an error, for example death-save failures.
- **Red Note** (#ffb3a8, Dark #ff9c8f) and **Blue Note** (#a9ccff, Dark #9cc4ff): the fills of the "failed" and information alert notes.
- **Flag Yellow** (#ffe45c), **Flag Blue** (#7fb6ff), **Flag Green** (#7ee08f), **Flag Orange** (#ffae5c): the tabs for Characters, Import, My Content and Preferences. They are the same in the two themes.
- **Stain** (#8c5a2b, Dark #c8915a) and **Stain Wash** (#a87442, Dark #c8915a): the mug stain on Home.

### Neutral

- **Raised Paper** (#ffffff, Dark #0a0a0a): stat boxes and boxed fields.
- **Muted Ink** (#595959, Dark #adadad): labels, secondary text, and the max of a current / max pair.
- **Rule** (#e3dece, Dark #222222): hairlines. Decoration only.
- **Strong Rule** (#8a8578, Dark #6b6b6b): box borders, section rules and the border of a disabled field.
- **Panel**: 6% Ink on Paper (`color-mix`). The shaded panel that groups related boxes, and the hover fill of a button.
- **Note Ink** (#222222, Dark #000000) and **Flag Ink** (#222222, Dark #000000): text on a note and on a flag tab.

### Named Rules

**The Role Token Rule.** Use only the role tokens of `packages/ui/theme.css`. The default Tailwind colors are removed from the app. Do not write a raw hex value in a component.

**The Red Means Failed Rule.** Red is never a tab color and never decoration.

**The Contrast Rule.** Text has a contrast of 4.5 : 1 or more on its background. Field borders and marks have 3 : 1 or more. The two themes obey this rule (WCAG 2.2 AA). A unit test in `packages/ui` computes each pair. When you add a text token, add its pair to the test.

**The Underlined Link Rule.** A link is Ink with an underline. It is not blue.

## Typography

**Display Font:** Newsreader Variable (with Georgia, Times New Roman, serif)
**Body Font:** Newsreader Variable (with Georgia, Times New Roman, serif)
**Label Font:** Inter Variable (with system-ui, -apple-system, Segoe UI, sans-serif)

**Character:** A book serif with an optical-size axis carries the content, as print does on a paper sheet. Small sans caps name the boxes and stay out of the way.

### Hierarchy

- **Display** (560, `clamp(52px, 10vw, 84px)`, line height 0.95, -0.02em): the "Alchemy 5E" wordmark on Home only.
- **Body** (450, 17px, line height 1.5): body text, headings and values. Numbers are tabular lining digits. Large values on the sheet use the same face at a larger size.
- **Label** (Inter 400, 10.5px, 0.08em, uppercase, Muted Ink): the label of a box or a field. The label above a field has weight 500. The six ability labels on the sheet are 13px.
- **Section label** (Inter 600, 11.5px, 0.08em, uppercase): a section title on a rule.
- **Button** (Inter 600, 13px, line height 1.4; 14px in a large button): button text.
- **Note** (Inter 500, 13.5px): alert notes. A note line is Inter 13.5px at the normal weight. Flag tab labels are Inter 600, 13.5px, uppercase.

The theme spec sets these sizes only. Each component sets the other sizes that it needs, for example the large value of a stat box (32px). Thus the detector rule `design-system-font-size` is off for the project (`.impeccable/config.json`).

### Named Rules

**The Self-Hosted Fonts Rule.** The fonts come from `@fontsource-variable/newsreader` and `@fontsource-variable/inter`. The app makes no font request to a third party.

**The Two Faces Rule.** Newsreader is for content and Inter is for labels and controls. Do not add a third face.

## Layout

- **Shell:** a 200px left rail holds the logo and the flag tabs. A double margin rule (1.5px, then 1px at 45%) separates the rail from the page. At 680px and less, the rail is a strip at the top, with the rule along its bottom and the tabs in a row on the rule.
- **Character sheet:** two columns at about 1 : 2, with a maximum width of 960px. The left column is 320px wide or more. Under 720px, the sections go in four tabs (Stats, Spells, Features, More) and the tab row sticks to the top.
- **Home:** one column: the title row, the tagline, the buttons, three facts, then Recent characters.
- **Dialogs:** a Dialog is 720px wide at most. At 600px and less, a Dialog and a ListModal fill the screen.
- **Density:** the sheet is dense, as a paper sheet is. Boxes are sized to their content. Forms are one column of labelled fields, with the label above the control.
- The page never scrolls sideways. Long values truncate with an ellipsis or wrap.

## Elevation & Depth

The system is flat. Depth comes from borders, from Raised Paper on Paper, and from the shaded Panel. Only things that are on top of the page cast a shadow: the notes, the current flag tab and a modal. The backdrop of a Dialog and of a ListModal is a 40% Ink wash.

### Shadow Vocabulary

- **Tab shadow** (`0 3px 6px -4px var(--note-shadow)`): the current flag tab.
- **Note shadow** (`0 4px 8px -5px var(--note-shadow)`, and `0 2px 3px -1px var(--note-shadow)` for an inline note): alert notes and inline notes. `--note-shadow` is `rgba(60, 45, 0, 0.2)`, and `rgba(255, 255, 255, 0.1)` in the Dark theme.
- **Modal shadow** (`0 22px 50px -18px var(--note-shadow)`): the Dialog and the ListModal.
- **Stuck note:** a `drop-shadow` filter, because the folded corner is a `clip-path`.

### Named Rules

**The Stuck Things Rule.** A box, a button and a field have no shadow. A shadow means that the thing is on top of the paper.

## Shapes

Borders do the work. A framed box has a 1.5px Strong Rule border and a 6px radius. Fields and tokens are square (radius 0), with a 1px Ink border. Buttons have a 6px radius, and small buttons and the X button have 4px. A checkbox mark has 2px. Slot circles and radio marks are circles. The use bubble has an 18px radius. Proficiency marks are filled squares. A note has a folded bottom-right corner. A stuck note has a tilt of about 2 degrees, and an alert note has no tilt. A flag tab is a flat flag shape.

## Components

The components are in `@orc-alchemy/ui` (`packages/ui`). The app imports controls only from that package. The package has no game words.

### Buttons

- **Shape:** 6px radius, 1.5px Ink border, padding 5px 12px.
- **Ghost (default):** a transparent fill and Ink text. Hover fills with Panel.
- **Solid:** an Ink fill and Paper text. A pressed Toggle and a current ghost button have the same look.
- **Link:** the text of its line, with an underline.
- **Disabled:** Muted Ink text and a Strong Rule border.
- **Wide:** the full width of its column, with the text on the left. The AddButton is a wide button with a count on the right.
- **X button:** a 30px square with an X of two lines and no text. Hover makes it Danger Red with a border.

### Chips

- **Token:** one pick on a form, as a small box with its name and an X.
- **Chips:** number chips with an X, and a dashed "+ Add" button.

### Cards / Containers

- **Framed box:** a value in a box with its label under it, in Label type.
- **Stat box:** a large value with a hanging oval for a second value, on Raised Paper.
- **Shaded panel:** a Panel area that groups related boxes.
- **Shadow Strategy:** none. See Elevation & Depth.

### Inputs / Fields

- **Style:** each TextInput, TextArea, Select, Combobox and NumberField is boxed: a 1px Ink border on Raised Paper, radius 0, padding 3px 8px. The label is above the control, in Label type.
- **Focus:** a 2px Info Blue outline with a 2px offset on `:focus-visible`. On a note, the outline is Note Ink. On a flag tab, it is Ink.
- **Error / Disabled:** error text is Danger Red. A disabled field has a Strong Rule border.

### Navigation

- **Flag tabs:** Inter 600, 13.5px, uppercase, in Flag Ink. A tab has a pale body (55% of its color on white) and a solid end at the rule. The current tab sticks out further, is solid and has a small shadow. Hover moves a tab out a little, but not under `prefers-reduced-motion: reduce`.
- **Home** has no tab. The logo in the rail links to it.

### Stuck note, alert note and note line

- **Stuck note:** a tilted Note Yellow note above the box that it marks. It takes its own space and overlaps only the top border of the box. It goes only where the user must act.
- **Alert note:** a flat note at the full width of the page column, above the content. Yellow means "you must act", red means "failed", and blue is information. Only a blue note has a dismiss button.
- **Note line:** a flat yellow line in the flow of a form, with a link button at its end.

### Use bubble

The frame around a feature with limited uses: an Info Blue outline, a Bubble fill and an 18px radius. One circle for each use, and a spent circle gets an ink slash. The rest type is in small caps in the top right. When all uses are spent, the outline becomes dashed Muted Ink.

### Slot circles and square marks

A row of plain circles, and a marked circle fills solid. The color is a prop: Ink for spell slots, Success Green for death-save successes, Caution Orange for failures. A filled square means "has it", for example a proficiency.

### Logo

The potion bottle, 16 × 16 pixel art. Show it only at a whole power-of-two scale, with `image-rendering: pixelated`. The liquid swirls in the rail and on Home, but not under `prefers-reduced-motion: reduce`.

## Do's and Don'ts

### Do:

- **Do** read `docs/design/theme.md` before you change a token, a control or a layout rule. It wins over this file.
- **Do** use the role tokens and the components of `@orc-alchemy/ui`.
- **Do** use the terms of `GLOSSARY.md`: stuck note, alert note, use bubble, picker, token.
- **Do** make each page work in the Light theme and the Dark theme, and at 390px wide.
- **Do** show a current / max pair as the current value at full size, then `/ max` in Muted Ink.
- **Do** obey `prefers-reduced-motion: reduce` for each motion.

### Don't:

- **Don't** let a stuck note cover the content of the box that it marks.
- **Don't** use a stuck note for information that needs no action. Use Warning Yellow text.
- **Don't** use red for a thing that did not fail.
- **Don't** import a control from `@base-ui/react` in the app. Import it from `@orc-alchemy/ui`.
- **Don't** add icons. The app uses text labels.
- **Don't** make the Dark theme a dark paper color. It is black and white.
- **Don't** load a font from a third party.
